# NW_crawling
네이버웹툰 정보 크롤링 (웹툰명, 회차, URL, 관심수, 좋아요수)

## 데이터 저장 형식
```json
      {
        "웹툰명": "",
        "회차": "",
        "URL": "",
        "관심수": "",
        "좋아요수": ""
      },
```


# 주의사항
- 성인인증이 필요한 웹툰은 크롤링 대상에서 제외됩니다.
- 웹사이트의 구조가 변경될 경우 크롤링이 정상적으로 작동하지 않을 수 있습니다.
- 과도한 요청으로 대상 서버에 부하를 주지 않도록 적절한 요청 간격과 동시 작업자 수를 설정해야 합니다.
- 로그인, 본인인증, CAPTCHA 등의 접근 제한을 우회하여 데이터를 수집하지 않습니다.
